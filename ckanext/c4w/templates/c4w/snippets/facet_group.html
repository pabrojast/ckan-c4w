Expects: name, title, options ([{term, label}]), counts ({term: n}). Options with a zero count are hidden -- a value that would return nothing is noise, and the counts already exclude this facet's own selection so an active value never hides itself. #} {% set counts = counts or {} %} {% set visible = options | selectattr('term', 'in', counts) | list %} {% if visible or h.c4w_facet_active(name, '') %}
